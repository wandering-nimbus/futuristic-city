## Tech Stack & Tools

* **Engine:** Unity
* **Language:** C#
* **Version Control:** Git + Git LFS (Large File Storage)
* **Pipeline**: Universal Render Pipeline (URP)
* **Target Platform:** PC

---

## Controls

By default, the vehicles are not moving when you first run the 3D scene.

| Action | Keyboard Key |
|---|---|
| **Move Camera** | `W`, `A`, `S`, `D` |
| **Front View** | `1` |
| **Left View** | `2` |
| **Back View** | `3` |
| **Right View** | `4` |
| **Top View** | `5`|
| **Zoom In/Zoom Out** | `Q`/`E`|
| **Start/Stop Cars** | `T` |
| **Start/Stop Drones** | `G` |
